01 — OBJECTIVE

What are we learning?

To create and manage a GitHub repository, work with branches, merge changes, and host a simple static website using GitHub Pages.

01

Create Repository

Store and manage project files in an online GitHub repository.

02

Branch & Merge

Make changes on a separate branch and merge them into the main branch.

03

Deploy Website

Publish the static website using GitHub Pages.

02 — PROCEDURE

Steps performed

01

Create a repository

Create a new repository on GitHub to store the project.

02

Create a branch

Create a separate branch to make and test changes safely.

03

Commit and merge

Commit the changes, then merge the branch into the main branch using a pull request or Git workflow.

04

Enable GitHub Pages

Select the main branch and root folder in Settings → Pages to publish the site.

Experiment completed!

A GitHub repository was created, branching and merging were practised, and a simple static website was prepared for hosting through GitHub Pages.
